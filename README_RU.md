# Deadcord v0.1 — пакет для Unity

Это стартовая реализация Deadcord для текущего прототипа `dead-line`: UI создаётся скриптом во время выполнения, текстовый контент хранится в JSON. Используются стандартные Unity UI (`Canvas`/`Text`/`InputField`/`ScrollRect`), TextMeshPro отдельно устанавливать не нужно.

## Установка за несколько минут

1. **Сделай копию проекта** или commit в Git.
2. Останови Play Mode в Unity.
3. Скопируй папку `Assets/Deadcord` из этого пакета в `Assets/` своего Unity-проекта. Должна получиться структура `Assets/Deadcord/...`.
4. Дождись, пока Unity закончит компиляцию. В `Console` не должно быть красных ошибок.
5. В `Hierarchy` найди объект, который указан в поле `Chat Panel` у компонента `ComputerInteraction` на компьютере. Это тот объект, который включается при нажатии `E`.
6. Добавь к этому же объекту компонент **`DeadcordRuntime`**. Поле `Hide Old Panel Children` оставь включённым: компонент отключит старые дочерние элементы окна чата и создаст новый интерфейс.
7. Убедись, что `ComputerInteraction.chatPanel` и `GameManager.chatPanel` указывают на этот же объект. Текущий `GameManager` автоматически используется для изменений репутации через `OnSuccess()` и `OnError()`.
8. Запусти сцену `MainScene`, подойди к компьютеру и нажми `E`. Закрыть Deadcord можно кнопкой `×` или клавишей `Escape`.

> Компонент нужно добавлять именно к UI-объекту панели компьютера, а не к `Computer`, `Player` или всему игровому `Canvas`, если в `ComputerInteraction.chatPanel` указан отдельный объект.

## Что реализовано

- Тёмный интерфейс Deadcord и сервера «Манулятник».
- Два канала: `#общий` и `#модерация`. Все сообщения пользователей и модератора идут в `#общий`; `#модерация` — только памятка и инструкции. Канала жалоб нет.
- NPC-ники собираются из трёх списков в `NameParts.json`; обычные пользователи сохраняют ник и цвет аватара в течение смены.
- Обычные реплики, нарушения и небольшая сюжетная последовательность загружаются из JSON.
- Один активный инцидент за раз, команды `/ban @Ник`, `/mute @Ник`, дополнительная `/unmute @Ник`.
- Таймер помощника: базовые 15 секунд с разбросом ±5 секунд. После истечения появляется `DeadcordHelper печатает...`; спустя небольшую задержку помощник отправляет правильную команду, если игрок не успел.
- Репутация использует существующие `GameManager.OnSuccess()` и `GameManager.OnError()`, если `GameManager` найден. Без него есть локальный резервный счётчик.
- Волны первого дня: через 45 секунд добавляется наказание за спам «АХАХА», через 90 секунд — за сообщения ЦЕЛИКОМ КАПСОМ. Предыдущие правила остаются активными.
- Новое сообщение вызывает `PlayNewMessageSound()`. Пока аудио-клип не задан, метод молча ничего не делает.

## Где менять контент

Файлы находятся в `Assets/Deadcord/Resources/DeadcordData/`:

- `NameParts.json` — части имён `first`, `second`, `third`; поддерживаются символы `_`, `-`, `#` в самих частях.
- `NormalMessages.json` — обычные сообщения.
- `Violations.json` — нарушения, минимальная волна, требуемая команда и варианты текста.
- `Day01Rules.json` — инструкции, анонсы и длительность каждой волны. Сейчас волны 1 и 2 длятся по 45 секунд; третья остаётся активной до конца смены.
- `Day01Story.json` — сюжетные реплики с `atSeconds`, `username` и необязательным `incidentCategory`. Время указано от начала смены в секундах.

JSON-файлы загружаются через `Resources.Load`, поэтому не перемещай их за пределы `Resources/DeadcordData`, если не меняешь код загрузчика.

## Настройка звука позже

1. Выбери или импортируй короткий аудиофайл в Unity.
2. Выбери объект с компонентом `DeadcordRuntime`.
3. Назначь клип в поле **New Message Sound**.
4. `AudioSource` будет создан автоматически, если ты не назначил собственный. В коде рядом с методом `PlayNewMessageSound()` есть комментарии `TODO AUDIO`.

## Принятые упрощения v0.1

- В каждый момент времени активен только один инцидент, чтобы первый прототип оставался предсказуемым.
- Пока все нарушения требуют `/ban`. `/mute` и `/unmute` работают как дополнительные команды, но не решают текущий инцидент, если его правило требует бан.
- Третья волна не заканчивается автоматически; это прототип одного дня с тремя этапами усложнения.
- Аватары — цветные плитки с инициалами; отдельные графические аватары можно добавить позже.
- Смена идёт, пока панель открыта. При закрытии Deadcord таймеры останавливаются и продолжаются после повторного открытия.
- Сообщения и сюжет сейчас пишутся в локальный UI, никакого реального Discord-соединения нет.

## Если не работает

- Если не появляется интерфейс, проверь, что `DeadcordRuntime` находится на том же объекте, который задан в `ComputerInteraction.chatPanel`.
- Если панель открывается, но не принимает ввод, проверь `EventSystem` в сцене. Скрипт создаёт его автоматически, если не находит существующий. Для проекта с Input System предпочтителен `InputSystemUIInputModule`.
- Если Unity сообщает об ошибке `GameManager`, проверь, что исходный `GameManager.cs` остался в проекте и класс всё ещё называется `GameManager`.
- Если UI находится в неверном масштабе, проверь ненулевой масштаб родительского Canvas и `RectTransform` панели.
